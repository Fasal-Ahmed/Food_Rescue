# Day 4 – Food Details and Rescue Management

This is the cumulative project through Day 4. It includes the earlier Day 1–3
work plus the food details and reservation workflow.

## Day 4 additions
- Food details screen with donor information and quantity selection.
- Reserve available food and reduce listing quantity.
- My Rescues screen to view reservations.
- Mark a reservation as collected or cancel it and return the quantity.

## Run
1. Open this `FoodRescue` folder in the terminal.
2. Run `npm install`.
3. Run `npx expo start`.
